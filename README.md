# 전세계 경제·투자 인사이트 아카이브 — 완전 자동화 버전

그날그날의 경제/시장 뉴스와 커뮤니티를 모아 **동적으로 이슈를
만들고**, 사안에 여러 해석이 있으면 **분석 프레임별로 나란히**
정리해서 하루 두 번(아침/저녁) 자동으로 쌓이는 개인 아카이브
사이트입니다. 한 번 세팅해두면 이후엔 신경 쓸 필요 없이 매일
자동으로 돌아갑니다.

> 이 사이트는 투자 자문이 아닙니다. 특정 종목/자산의 매수·매도를
> 권유하지 않으며, "무슨 일이 있었고 왜 중요한지"를 정리하는
> 뉴스 인텔리전스입니다. 투자 판단은 반드시 원문과 전문가 확인을
> 거쳐 본인 책임 하에 하시기 바랍니다.

## 지금 사용자님이 해야 할 일은 기본 3가지 + 선택 1가지입니다

### 1. GitHub 저장소 만들기
- github.com 에서 새 저장소(Repository) 생성 (Public으로)
- 이 폴더 전체(파일들)를 그 저장소에 업로드

### 2. API 키를 비밀값(Secret)으로 등록
- 저장소의 **Settings → Secrets and variables → Actions → New repository secret**
- 이름: `ANTHROPIC_API_KEY`
- 값: [console.anthropic.com](https://console.anthropic.com)에서 발급받은 API 키

### 3. GitHub Pages 켜기
- 저장소의 **Settings → Pages → Build and deployment → Source**를
  "GitHub Actions"로 설정

### 4. (선택, 강력 추천) 실제 시세 차트를 보려면 `FRED_API_KEY` 추가
- 이 사이트는 뉴스 텍스트뿐 아니라 **S&P500/나스닥/다우, 미국 국채
  금리, WTI/브렌트유의 실제 시세 데이터를 스파크라인 차트로** 함께
  보여줍니다 (암호자산·환율 차트는 키 없이 자동으로 나옵니다).
- [fredaccount.stlouisfed.org](https://fredaccount.stlouisfed.org)에서
  무료 계정을 만들고 API 키 페이지에서 키를 즉시 발급받으세요
  (완전 무료, 가입만 하면 됩니다).
- 저장소 Secrets에 이름 `FRED_API_KEY`로 등록하세요.
- **이 단계를 건너뛰어도 사이트는 정상 작동합니다** — 주식/채권/
  원자재 쪽 차트 카드만 조용히 빠지고, 암호자산·환율 차트와 모든
  텍스트 인사이트는 그대로 나옵니다.

**이게 끝입니다.** 이후로는 매일 한국시간 아침 6시(06:13)와 저녁
6시(18:13)에 자동으로: 경제/투자 뉴스·커뮤니티 수집 → 자산군별
실제 시세 데이터 수집 → 이슈 클러스터링 + 다중 분석 프레임 요약 →
사이트 생성 → `https://[사용자이름].github.io/[저장소이름]/` 에
자동 배포됩니다.

바로 오늘 실행해보고 싶다면, 저장소의 **Actions 탭 → "경제·투자
인사이트 아카이브 생성 및 배포" → Run workflow** 버튼을 눌러
수동으로도 즉시 실행할 수 있습니다.

## 다루는 범위

거시경제 지표, 통화정책/중앙은행, 재정정책, 기업 실적·M&A,
주식·채권·외환·원자재·암호자산 시장, 무역/공급망/관세, 규제·정책이
자본시장에 미치는 영향, 그리고 지정학·재난이 에너지/물류/금융시장에
뚜렷한 파급을 미치는 경우까지 다룹니다. 순수 정치·연예·스포츠·범죄
등 경제적 파급이 불분명한 것은 자동으로 걸러집니다 (`config.py`에
일부 종합 뉴스 피드도 포함되어 있는데, 이는 그 지역의 경제 파급을
놓치지 않기 위함이며 실제 필터링은 Claude가 1단계에서 수행합니다).

## 자산군(주식/채권/원자재/암호자산/외환) 커버리지

`config.py`에는 지역별 경제 피드와 별도로 "Global" 섹션에 자산군별
전문 소스(Investing.com의 주식/채권·경제지표/외환/원자재/암호자산
카테고리, FXStreet, CoinDesk·Cointelegraph, OilPrice.com 등)를 넣어
특정 자산군 뉴스가 지역 뉴스에 묻히지 않도록 했습니다.

파이프라인은 매 세션마다 각 이슈에 관련 자산군 태그(주식/채권·금리/
원자재/암호자산/외환)를 붙이고, 최종 선별 단계에서 "이번 세션에
실제로 유의미한 뉴스가 있었던 자산군을 놓치지 않았는지" 점검합니다
(강제로 5개를 다 채우는 것은 아니고, 뉴스가 없으면 없다고 그대로
표시합니다). 사이트 상단에는 5개 자산군을 한눈에 훑을 수 있는
"마켓 펄스" 스트립이 매 페이지마다 생성됩니다.

## 실제 시세 차트 (뉴스 텍스트 + 숫자·추세선을 함께)

뉴스 요약만으로는 "그래서 실제로 얼마나 움직였는지" 추세가 잘 안
보이기 때문에, `market_data.py`가 아래 공식 무료 API에서 실제
시계열 데이터를 가져와 작은 추세선(스파크라인)과 등락률을 함께
보여줍니다. 별도 차트 라이브러리나 JS 없이 순수 SVG로 그려서
정적 사이트 그대로 유지됩니다.

| 자산군 | 데이터 소스 | 키 필요 여부 |
|---|---|---|
| 주식 (S&P500/나스닥/다우) | FRED (세인트루이스 연은) | 필요 (무료) |
| 채권·금리 (10년물/2년물/기준금리) | FRED | 필요 (무료) |
| 원자재 (WTI/브렌트유) | FRED | 필요 (무료) |
| 암호자산 (BTC/ETH) | Kraken 공개 API | 불필요 |
| 외환 (원/달러, 달러/엔, 유로/달러) | Frankfurter API | 불필요 |

이 차트는 두 곳에 나타납니다: ① 상단 "마켓 펄스" 카드 안에 자산군
대표 종목, ② 각 이슈 카드 안에 그 이슈가 태깅된 자산군의 실제
시세(최대 2개) — 뉴스가 "국채금리가 하락했다"고 말할 때 바로 옆에
실제 국채금리 추세선이 함께 보이는 식입니다. `FRED_API_KEY`를
등록하지 않으면 주식/채권/원자재 차트만 조용히 빠지고 나머지는
정상적으로 나옵니다 (크래시 없음).

## 비트코인/암호자산 공포·탐욕 지수 (Fear & Greed)

`market_data.py`가 [alternative.me](https://alternative.me/crypto/fear-and-greed-index/)의
무료 공개 API(키 불필요)에서 매 세션 최신 지수를 가져와 "암호자산"
마켓 펄스 카드 안에 작은 반원 게이지로 보여줍니다. 0(극단적 공포)~
100(극단적 탐욕) 사이 값과 전일 대비 변화가 함께 표시되며, 이
API 호출이 실패해도 게이지만 조용히 빠지고 나머지 사이트는 정상
생성됩니다.

## 실시간 마켓 위젯 (TradingView, index.html 전용)

아카이브 목록 페이지(`site/index.html`) 상단에는 [TradingView의
공식 무료 임베드 위젯](https://www.tradingview.com/widget/)이
추가로 들어갑니다 — API 키나 별도 스크립트 설치 없이 `<iframe>`
하나로 동작하며, 실시간 갱신은 TradingView 쪽에서 처리합니다.

- 자산군별 실시간 미니 시세 12종 (S&P500·닛케이·DAX·MSCI 한국,
  미 10년물 금리·20년 국채 ETF, 금·WTI, 비트코인·이더리움,
  달러/원·달러 인덱스)
- 탭으로 전환되는 마켓 오버뷰 위젯 (주요 지수 / 선물·원자재 /
  외환·통화 / ETF)

이 위젯들은 "지금 이 순간"의 실시간 시세이기 때문에, 과거 특정
세션을 다루는 날짜별 아카이브 페이지(`site/{날짜}-{세션}.html`)에는
넣지 않고 index.html에만 넣었습니다 (지난 세션 페이지에 실시간
데이터가 섞여 보이면 혼동을 줄 수 있어서입니다). TradingView 위젯은
로컬(`file://`)에서 미리보기할 때는 인터넷 연결이 있어야 정상
로드되며, 실제 배포된 GitHub Pages 사이트에서는 그대로 동작합니다.

## 파일 구조

```
run_pipeline.py             전체 과정을 한 번에 실행하는 진입점
config.py                   경제/투자 RSS·커뮤니티 소스 목록
fetch_sources.py            이번 세션 아이템 수집
market_data.py              자산군별 실제 시세 데이터 수집 (FRED/Kraken/Frankfurter)
cluster_and_summarize.py    Claude API로 이슈 클러스터링 + 다중 분석 프레임 요약
generate_site.py            아카이브 JSON → 정적 HTML 사이트 (텍스트 + 시세 차트)
.github/workflows/daily.yml 하루 두 번 자동 실행 + Pages 배포 설정
archive/                    세션별 원본 데이터 (자동 누적)
site/                       배포되는 최종 HTML (자동 생성)
```

## 로컬에서 미리 테스트하고 싶다면 (선택사항)

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY="sk-ant-..."
export FRED_API_KEY="..."   # 선택사항 — 없어도 실행되며, 주식/채권/원자재 차트만 빠짐
python3 run_pipeline.py
open site/index.html   # 결과 미리보기
```

## 법적/윤리적 원칙 (이미 코드에 내장되어 있음)

- 원문 전체를 저장하지 않고, RSS의 짧은 발췌 + Claude가 재구성한
  2~3문장 요약만 사용합니다.
- 모든 카드에 원문 출처와 링크가 항상 표시됩니다.
- 여러 시각이 있는 사안은 하나로 뭉개지 않고 분석 프레임별로
  병기합니다.
- 특정 종목/자산의 매수·매도를 권유하는 문구는 프롬프트/사이트
  어디에도 두지 않으며, 매 페이지 하단에 투자 자문이 아니라는
  문구를 고정 노출합니다.
- 커뮤니티 사이트(Reddit 등)를 상업적으로 크게 키울 계획이면 추후
  공식 API(OAuth)로 전환을 검토하세요.

## 나중에 확장하고 싶어지면

- `config.py`에 원하는 거래소/중앙은행/언론사 RSS 추가 (RSS 주소만
  넣으면 됨). RSS 주소는 언론사 사정으로 바뀔 수 있으니, 수집 실패
  로그가 늘어나는 소스는 최신 주소로 다시 확인하세요.
- 특정 자산군(예: 암호자산, 원자재)만 따로 모은 필터/서브페이지 추가
- 이메일 뉴스레터 발송 (Resend/Mailchimp 등 연동)
- 커스텀 도메인 연결 (GitHub Pages 설정에서 가능)
- 디자인은 이후 클로드 디자인으로 `site/` HTML을 다듬어도 됨
